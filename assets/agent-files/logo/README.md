# Agent Files — Logo

The mark is a file with a lock on its corner. It stands for the two files this
library writes, `auth.json` and `settings.json`, without replacing a symlink or
changing an existing mode. Palette and type follow the same Path Blue / Manrope
family as the other package marks.

## Files

**Vector**

- `agent-files-mark.svg` — mark, ink from `currentColor`, Path Blue lock.
- `agent-files-mark-white.svg` — mark pre-colored for dark backgrounds.
- `agent-files-lockup.svg` — horizontal mark plus "Agent Files".
- `agent-files-icon.svg` — square tile, paper mark on Path Blue.
- `agent-files-favicon-32.svg` — simplified tile for 32px.

**Raster**

- `agent-files-icon-512.png` — raster of the tile.
- `agent-files-mark-512.png` — raster of the mark.
- `agent-files-favicon-32.png` — raster of the favicon.

**Gallery (one level up)**

- `../preview.png` — package README header. Same tile as the icon.

## Color

| Role    | Value     |
| ------- | --------- |
| Accent  | `#3465a4` |
| Ink     | `#4c4f69` |
| Paper   | `#eff1f5` |
| Surface | `#1e1e2e` |

## Don't

- Recolor the lock to ink, or the wordmark to blue.
- Add gradients, glows, or shadows.
