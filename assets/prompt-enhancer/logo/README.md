# Prompt Enhancer — Logo

The mark is a prompt caret and line with a sparkle above it: a rough request
being refined. Same Path Blue / Manrope family as Headroom and Steward.

## Files

- `prompt-enhancer-mark.svg` — mark only, Path Blue, transparent
- `prompt-enhancer-icon.svg` — app icon: white mark on a Path Blue rounded tile

## Color

- **Path Blue** `#3465a4` — the mark, the icon tile
- Icon tile corner radius is ~23% of the tile (rx 15 on a 64 grid), matching Headroom.

## In-terminal glyph

The Pi widget uses Nerd Font `nf-md-auto-fix` (U+F0068), the magic wand.
Override with `PROMPT_ENHANCER_GLYPH`; set it empty to drop the mark.
